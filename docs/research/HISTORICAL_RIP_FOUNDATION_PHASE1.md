# Historical Collector Appeal and RIP — Phase 1

The historical foundation is structurally designed but longitudinal V7 research is blocked by source depth. Exact V7 begins on 2026-09-11 and currently contains one 128-set observation day. Applying September Trends or Playability evidence to earlier dates would be lookahead leakage.

Google documents that Trends website results are sampled and normalized to the requested time and location. The alpha API advertises consistently scaled data over a rolling five-year window, but it is not an approved or captured project authority. Historical-query retrieval therefore remains research-only until repeated-query stability and anchor comparability are demonstrated.

The repository now contains leakage-safe source selection, explicit effective-period handling, cohort fingerprinting, quality-state filtering, idempotent history identity, and preliminary historical-feature primitives. No schema was deployed and no backfill was written because the evidence gate failed.

Collector V5/V6/V7 must remain separate series. Historical analytics default to READY and RECONSTRUCTED_VALIDATED only. Overall RIP remains unchanged.
