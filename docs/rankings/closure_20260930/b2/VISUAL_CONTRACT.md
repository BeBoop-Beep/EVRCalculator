# Bucket 2 visual contract

## Benchmark headline score

- Purple outlined score badge remains.
- Numeric value remains unchanged and displays `/10` only for the benchmark-10 contract.
- Table/section heading names the metric; the badge does not repeat it visibly.
- No benchmark direction arrow or delta decoration.
- Screen readers retain metric name and rank/cohort context.

## Component score

- One neutral, bold, tabular number.
- `—` is reserved for null/non-numeric unavailable data.
- No tier color, colored border/background, internal visible label, or direction arrow.
- Desktop context comes from the column heading. Mobile values carry an accessible metric label; card layouts that use `dl` retain visible `dt` labels.

## Set identity

- Use `SetIdentity`; prefer logo, then symbol, then initials.
- Keep artwork compact and beside identity text.
- Pack hierarchy remains Set -> family -> exact Product; B2 changes only parent Set identity.
- Product/Card artwork stays primary and is never replaced by Set artwork.

## Rankings controls

- Selected text is white with a neutral translucent white surface/border.
- Unselected state remains visibly distinct.
- Focus-visible ring remains present.
- No yellow, green, or green-yellow selected treatment.
- Scope is opt-in Rankings variants/classes; unrelated site controls keep their current styling.
